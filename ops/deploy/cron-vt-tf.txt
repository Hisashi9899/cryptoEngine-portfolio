# V.T足種追加 cron（VPS 追記分のみ・5分足は既存維持）
# インストール（VPS 上で冪等）:
#   bash /opt/cryptoengine/ops/deploy/install-vt-cron.sh [--apply]
# 仕様: 1銘柄1建玉・発注なし。ファイル名・退避は足種別で分離済み
# （vt_signals_<SYM>_<bars>_<日>.jsonl / vt_open_<SYM>_<bars>.json）。
# テープCSVは全足種で共有追記（エンジン内CVDはプロセス毎に独立のため無影響）。
